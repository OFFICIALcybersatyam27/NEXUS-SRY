🌐 What is NEXUS-SRY?

NEXUS-SRY is a security research and information-gathering project created by OFFICIAL_cyber_satyam27.

The project focuses on collecting basic technical information through transparent, permission-based interactions.

Information Categories

- Device Information
- Operating System
- Browser Information
- Screen Resolution
- Public IP Information
- Network Information
- Location Information (only with explicit user permission)

⚡ Features

- Modern and user-friendly interface
- Lightweight design
- Automated information processing
- Organized data presentation
- Privacy-conscious approach
- Educational security research
- Cross-platform development goals

💻 Supported Platforms

NEXUS-SRY is intended for development and testing on:

- Kali Linux
- Termux
- Ubuntu
- Debian
- Windows (WSL)
- Parrot Security OS
- macOS

Compatibility depends on the implemented features and dependencies.

📦 Requirements

- Git
- Bash
- Internet connection
- Required project dependencies

🚀 Installation

Clone the repository:
```
git clone https://github.com/OFFICIALcybersatyam27/NEXUS-SRY.git
```
Enter the project directory:
```
cd NEXUS-SRY
```
Run the project:
```
bash nexus.sh
```
Note: Replace the execution command with the actual startup filename if your project uses a different entry point.
